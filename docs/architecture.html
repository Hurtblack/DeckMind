一次请求的时序示例 — "把音量调到 50%"

User  →  Agent.handle("把音量调到 50%")
            │
            ├─ memory.add_user(...)
            ├─ history = memory.snapshot()
            │
            │  ── Step 1 ──────────────────────────────────────────
            ├─ Planner.next_step(history)
            │     └─ LLM 返回: function_call(name="set_volume", args={percent:50})
            ├─ history.append(function_call)
            ├─ Executor.run("set_volume", {percent:50})
            │     └─ subprocess: wpctl set-volume @DEFAULT_AUDIO_SINK@ 0.50
            │     └─ result: {ok:true, percent:50, backend:"wpctl"}
            ├─ history.append(function_call_output)
            │
            │  ── Step 2 ──────────────────────────────────────────
            ├─ Planner.next_step(history)
            │     └─ LLM 返回: function_call(name="final_answer",
            │                                args={message:"Volume set to 50%."})
            ├─ name == "final_answer" → break
            │
            ├─ memory.add_assistant("Volume set to 50%.")
            └─ return "Volume set to 50%."

bot> Volume set to 50%.
